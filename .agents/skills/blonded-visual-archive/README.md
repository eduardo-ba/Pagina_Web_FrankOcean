# Blonded Visual Archive skill

Skill repo-scoped para rediseñar el proyecto Astro de Frank Ocean como una experiencia editorial, fotográfica y experimental.

## Instalación en el repositorio

Copia esta carpeta a:

```text
.agents/skills/blonded-visual-archive/
```

Después abre Codex desde la raíz del repositorio y usa:

```text
$blonded-visual-archive Rediseña el proyecto completo siguiendo la skill. Empieza con el inventario y el plan, luego implementa página por página.
```

## Scripts incluidos

```bash
node .agents/skills/blonded-visual-archive/scripts/inventory-assets.mjs
node .agents/skills/blonded-visual-archive/scripts/check-archive.mjs
```

## Nota

La skill no incluye ni redistribuye imágenes o fuentes. Trabaja con los recursos que ya existen en el proyecto y con los que el usuario agregue legalmente.
